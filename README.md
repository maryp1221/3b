# Практическое задание 3Б — Справочник пользователей

Веб-приложение для просмотра пользователей, поиска по имени и загрузки публикаций с использованием REST API.

**Технологии:** HTML, CSS, JavaScript (без фреймворков).

## Запуск проекта

1. Распакуйте ZIP-архив.
2. Откройте файл `index.html` в браузере.
3. Убедитесь, что есть подключение к интернету: сведения загружаются из публичного API.

Устанавливать дополнительные программы не требуется.

## Возможности приложения

- Загрузка 10 пользователей GET-запросом к `https://jsonplaceholder.typicode.com/users`.
- Отображение имени, email и города.
- Поиск по имени без нового HTTP-запроса, без учёта регистра.
- Загрузка первых трёх публикаций выбранного пользователя через `GET /posts?userId=ID`.
- Сообщения о загрузке, об ошибках и об отсутствии совпадений.
- Повторная попытка после ошибки; обновление страницы без перезагрузки.

## Результаты проверки по коду

| Проверка | Ожидаемый результат / реализация |
|---|---|
| Нажатие «Загрузить пользователей» | Выполняется GET-запрос и отображаются данные пользователей |
| Поиск «Leanne» | Остаётся подходящий пользователь; повторный HTTP-запрос не выполняется |
| Поиск неизвестного имени | Появляется «Пользователи не найдены» |
| Нажатие «Показать публикации» | Выводятся заголовки и тексты максимум трёх публикаций пользователя |
| HTTP 404 (временно заменить `/users` на `/userz`) | Показывается сообщение с кодом HTTP, после исправления URL возможна повторная загрузка |
| Сетевой сбой | Отображается ошибка; кнопка загрузки становится доступной снова |
| Во время запросов | Выводится «Загрузка...», кнопка загрузки пользователей временно отключена |

**Примечание:** перечислены проверки реализации по исходному коду. Для окончательной проверки в браузере требуется интернет. Чтобы проверить HTTP 404, временно измените `USERS_URL` в `app.js` на `https://jsonplaceholder.typicode.com/userz`, затем верните исходный адрес.
